# Passo Rosa – site de calçados femininos

Site estático (HTML, CSS e JS em um único `index.html`) com imagens na pasta `images/`. Sem carrinho: todos os botões abrem o WhatsApp com a mensagem do modelo.

## Antes de publicar
1. **WhatsApp:** busque e substitua `5511999999999` pelo número real (formato 55 + DDD + número) em `index.html`.
2. **Domínio:** substitua `https://www.exemplo.com.br` pelo domínio real em `index.html`, `robots.txt` e `sitemap.xml`.
3. **Instagram, endereço e horários:** ajuste no rodapé e no bloco JSON-LD (`<script type="application/ld+json">`).
4. **Fotos:** troque os arquivos em `images/` mantendo os nomes (ou ajuste o `src` e o `alt`). Use fotos de 800 px ou mais.
5. **Google Analytics (opcional):** se instalar o gtag, os cliques no WhatsApp já enviam o evento `whatsapp_click`.

## Publicar no GitHub Pages
Suba os arquivos na raiz do repositório e vá em Settings > Pages > Deploy from a branch > `main` / root.

## Depois de publicar
Cadastre o site no Google Search Console e envie o `sitemap.xml`. Crie também o Perfil da Empresa no Google.
